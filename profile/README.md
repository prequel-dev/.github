### Welcome to Prequel

Prevent incidents and be production ready with community-driven problem detection.

The main repo is here: [Common Reliability Enumerations (CREs)](https://github.com/prequel-dev/cre)

[preq](https://github.com/prequel-dev/preq) (prounounced "preek") is a free and open community-driven reliability problem detector. Use preq to:

- detect the latest bugs, misconfigurations, anti-patterns, and known issues from a community of practitioners
- provide engineers, on-call support, and SRE agents with impact and community recommended mitigations
- hunt for new problems in logs

Docs: https://docs.prequel.dev/
